# Support and device testing

MobileFilmLab is an experimental public beta primarily developed for **Oppo Find X9 Ultra**. We plan to expand compatibility with beta testers' help. Availability on a different phone or firmware is not guaranteed.

- Start with the [testing guide](docs/TESTING.md) and [known limitations](KNOWN_LIMITATIONS.md).
- Report reproducible problems through the [bug form](https://github.com/TheSwagInDisguise/MobileFilmLab/issues/new?template=bug_report.yml).
- Share working/partial/unsupported configurations through the [device compatibility form](https://github.com/TheSwagInDisguise/MobileFilmLab/issues/new?template=device_support.yml).
- Use [security guidance](SECURITY.md) for security concerns, not public disclosure of credentials or sensitive photos.

Please include app version, model, Android/firmware, enabled lens/crop and processing settings. Capability reports help; review/redact them before posting. Public issue attachments are public. Do not upload private photos, location data, keystores, tokens or passwords.

There is no guaranteed response time or proprietary camera support service. Contributions, careful bug reports and hardware validation are welcome. See [contributing](CONTRIBUTING.md) and the [AI-development disclosure](docs/AI_DISCLOSURE.md).
