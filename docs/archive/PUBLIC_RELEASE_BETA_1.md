- The nine old release entries, `v0.1.0-alpha.1` through `.9`, and their APK/checksum/testing assets were removed from GitHub Releases.

- Previously downloaded, redistributed or cached copies cannot be revoked. Removing an official release does not erase copies held elsewhere.

Do not recreate withdrawn public binary releases inadvertently. Future publication still requires explicit approval of the intended tag. The automatic workflow defaults prerelease-version tags to prereleases; the current regular-release classification was an owner-authorised promotion of an existing verified entry, not a blanket change in future release policy.
