# Contributing to MobileFilmLab

Thank you for your interest in contributing!

## Code of Conduct
Please maintain a respectful, constructive, and collaborative environment.

## Development Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/TheSwagInDisguise/MobileFilmLab.git
   cd MobileFilmLab
   ```
2. Open in Android Studio Iguana or newer with JDK 17 / JDK 21.
3. Build and test locally:
   ```bash
   ./gradlew test
   ./gradlew assembleDebug
   ```

## Commit & Pull Request Guidelines
* Keep commits focused, descriptive, and atomic.
* License compliance: MobileFilmLab is licensed under **GPL-3.0-or-later**. All contributions must be compatible with GPL-3.0.
* Do not introduce closed-source dependencies, proprietary tracking, or analytics.
